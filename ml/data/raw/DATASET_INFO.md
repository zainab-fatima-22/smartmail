# Dataset Info — SmartMail Training Data

## Dataset name
`emails.csv` (SmartMail Synthetic Email Dataset v1)

## Source
**Synthetically generated** by `ml/src/generate_dataset.py` using hand-written
sentence templates per category, combined with randomized filler values
(names, companies, percentages, dates, etc.) to create realistic variety.

No public dataset was used as a base. No private, personal, or real
individuals' emails were used anywhere in this project.

## License
N/A — generated by this project, free to use for this educational project.

## Columns
| Column       | Type   | Description                                  |
|--------------|--------|-----------------------------------------------|
| email_text   | string | The email body text                           |
| category     | string | One of: spam, promotional, work, personal, important, social |

## How it was created
1. Each of the 6 categories has 10 hand-written sentence templates that
   reflect realistic phrasing for that category (e.g. spam uses prize/urgency
   language, work uses meeting/deadline language).
2. Templates contain placeholders (e.g. `{amount}`, `{day}`, `{company}`)
   that are filled with randomized values from small vocabulary lists.
3. Optional greeting/closing phrases are randomly prepended/appended to
   increase sentence variety further.
4. Duplicate sentences are rejected until each category reaches 120 unique
   rows, for a total of **720 rows** (perfectly balanced across classes).
5. Rows are shuffled with a fixed random seed (42) for reproducibility.

## Category mapping
No mapping was needed — categories were generated directly as:
spam, promotional, work, personal, important, social.

## Known limitations
- **This is synthetic data, not real-world email data.** Real inboxes contain
  far messier language, typos, HTML artifacts, longer threads, and much more
  vocabulary diversity.
- Templates create some repetitive sentence structure within a category,
  which can make the model rely on surface patterns (e.g. specific words
  like "won" or "meeting") rather than deeper semantic understanding.
- Category boundaries are fuzzier in real life than in this dataset — for
  example, real "Promotional" and "Spam" emails, or "Work" and "Important"
  emails, overlap much more than these clean templates do.
- Because of the above, do not treat this model's accuracy as representative
  of real-world spam/email classification performance. It is meant to
  demonstrate a complete, working ML pipeline for learning purposes.

## Regenerating the dataset
```
python ml/src/generate_dataset.py
```
This is deterministic (fixed random seed) and will always produce the same
720-row dataset.
